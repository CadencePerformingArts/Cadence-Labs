Data Practices

Draft · last edited August 2026 · not yet in effect

This page is the plain inventory: what Cadence collects, where it lives, how to get it out or deleted, and how the public competition data on the scoreboards is sourced. The Privacy Policy covers the same ground in policy form.

What is collected

  • Usage analytics — self-owned, no third parties. Cadence records its own page-view and action events in its own database. There are no third-party trackers, analytics scripts, or pixels anywhere on the site. When a signed-in user generates an event, the user_id on that event is stamped server-side by a database trigger from the authenticated session — the client cannot set or spoof it, and signed-out events carry no user identity.
  • Account email. The one piece of personal data a Cadence account requires. Used for magic-link sign-in and notifications.
  • Workspace content. Everything an organization puts into its Cadence Ensemble workspace — posts, messages, calendar and attendance, form responses, drill — stored in Supabase (hosted Postgres) with row-level security: the database itself decides which member may read which row, based on the organization's roles and settings.
  • Uploaded files. Stored in a private Supabase storage bucket. Nothing uploaded is ever public: files are reachable only through short-lived signed URLs minted for a signed-in member whose database permissions allow them to read that file.

Export

An organization can request an export of its workspace data — announcements, messages, calendar, attendance, form responses, file inventory — via the contact address published on the Cadence site. Export is intended to be available regardless of subscription state; an expired workspace is read-only, not hostage.

Deletion and the recovery period

  • Any person can request deletion of their account and personal data; an organization can request deletion of its entire workspace.
  • Deletion requests are honored, with a recovery period before permanent removal so that a mistaken or malicious request (for example, from a compromised email inbox) can be reversed. After the recovery period, the data is permanently removed, including from routine backups as they expire.
  • Inside a workspace, day-to-day "delete" actions are deliberately soft (archived posts, soft-deleted messages) so organizations keep their own history; that is separate from a true deletion request, which removes data from Cadence entirely.
  • The exact length of the recovery period will be fixed in the final version of these documents.

Public competition data

  • The scores, schedules, and results on Cadence scoreboards are factual competition data gathered from the circuits' own official public sources, then verified before publication. Cadence never fabricates, estimates, or extrapolates a score — if a number is not published, it is not on Cadence.
  • Corrections and takedown requests from circuits, event partners, or rights holders are honored; send them to the contact address published on the Cadence site.
  • The circuit's own publication is always the authoritative record; Cadence is a convenient mirror with history and statistics.

Non-affiliation

Cadence is an independent, unofficial project. It is not affiliated with, endorsed by, or sponsored by Drum Corps International (DCI), Winter Guard International (WGI), Bands of America, UIL, or any other circuit, league, or event organizer. Circuit and event names appear on Cadence solely to identify which public competition results are being shown.

Contact

Export requests, deletion requests, corrections, and takedown notices go to the contact address published on the Cadence site.
